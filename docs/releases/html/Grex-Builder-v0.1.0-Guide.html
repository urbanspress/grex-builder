1. What This Release Delivers (In Plain English)

Grex Theme Builder v0.1.0 is the first working release of a visual page and theme editor built specifically for GrabLab websites. Unlike traditional website builders that bolt on heavy JavaScript frameworks (Vue, React, Pinia, Webpack, Vite) and messy nested <div> boxes, Grex Theme Builder runs directly on native Grex JS v1.0.0 reactive signals, compiles clean HTML5 semantic layouts (zero wrapper <div> tags), and plugs straight into GrabLab CMS v1.0.0 with one click.

Exclusive Visual Mode Guarantee: When you activate the grex-builder theme package in GrabLab (/admin/themes), GrabLab automatically turns off any previous coded theme and hands 100% of page rendering and template control to Grex Theme Builder—cleanly and without theme conflicts.

  • Typography & Media (7): Heading (<h1>–<h6>), Text, RichText, Link, Button, Image, Icon.

4. Safety, Security & Accessibility Built In

  • Strict Zero-<div> Policy: Neither the Studio UI, the preview canvas, nor any GrabLab template emits wrapper <div> tags.
  • Fail-Closed Cross-Frame Messaging: GrexPreviewBridge refuses wildcard (*) or untrusted origins and validates message origins strictly.
  • Server & Client Security Boundaries: Raw <script>, <iframe>, on* event handlers, innerHTML sinks, and javascript: / data: URLs are rejected with HTTP 422 before saving or publishing.
  • Publish-Time WCAG AA Gate: Heading hierarchy, accessible button/link labels, alt text on images, form labels, and contrast diagnostics block unsafe publishes automatically.

5. How to Launch & Verify Locally

  1. Run migrations for the standalone studio database: grab migrate --db-config grab.data.json --allow-db main:migrate migrations/001_studio_schema.grab
  2. Start the studio server: grab serve --allow-scripts --db-config grab.data.json --allow-db main:read-write --platform-config grab.platform.json --allow-cache studio:read-write --static public --allow-read . --allow-write public/grex src/studio.grab
  3. Open http://127.0.0.1:8080/studio in a modern browser—or install theme/ inside GrabLab CMS v1.0.0 under themes/grex-builder and click Activate in /admin/themes.
  4. Run the full automated verification suite anytime with python tests/integration_e2e.py.
