Plain-English Summary: Grex Theme Builder v1.0.0 marks the production freeze of Step 3 in the GRAB Ecosystem. It delivers a complete, zero-build visual page and conditional theme studio powered purely by Grex JS v1.0.0 reactive signals, compiling clean zero-wrapper-<div> layouts and integrating with GrabLab CMS v1.0.0 through a single-click exclusive mode: "visual" theme package.

1. Complete Production Capabilities in v1.0.0

  • Exclusive mode: "visual" GrabLab Theme Contract: Packaged in theme/theme.json ("version": "1.0.0", "mode": "visual", "engine": "grex-visual") with 20 native semantic blocks (theme/grex.elements.json) and 9 clean .grab.html site templates and reusable parts.
  • Design System, Reusable Classes & Responsive Breakpoints: Edit site-wide --grex-* colors, typography, spacing, Light & Dark themes, Bricks-style .grex-c-* classes, and Desktop / Tablet / Mobile styles with live WCAG AA contrast warnings (GREX-A11Y-001).
  • Conditional Theme Builder, Query Loops & Pickers: Assign templates by route, content type, taxonomy term, or slug with automatic conflict detection (GREX-TPL-CONFLICT), build ForEach Query Loops, bind dynamic fields with exact decimal precision, choose accessible media & navigation menus, and switch live Preview As contexts.
  • Immutable Revisions, Zero-FOUC Rollback & AI Guardrails: Every Publish saves a deduplicated snapshot in template_revisions, supports isolated historical preview and one-click CSS-first rollback, keeps GRAB-DESIGN-SYSTEM.md synced at GET /api/design-system.md, and validates grab mcp / Groxy AI layout edits (POST /api/mcp/layout) against schema, XSS, and WCAG AA rules with 1-click Undo.
  • Pre-v1.0.0 Production Hardening & --read-only Docker Deployment: Adds GET /_ready, server-side attrs/styles sanitization (GREX-SEC-003 / GREX-SEC-004), Publish-time WCAG AA enforcement, independent immutable Studio chrome styling, and hardened deploy/docker-compose.yml templates (read_only: true, cap_drop: ALL, strictly scoped writable mounts).
