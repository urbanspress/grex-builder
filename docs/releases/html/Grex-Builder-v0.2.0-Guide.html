Grex Theme Builder · Release v0.2.0

Grex Theme Builder v0.2.0

Global Theme Token Studio, Reusable Class Manager & Responsive Breakpoints

Built on GRAB v1.1.0 · GrabLab CMS v1.0.0 · Grex JS v1.0.0 · Pure Reactive Signals (Zero Vue/Webpack Bloat)

1. What’s New in Plain English

Grex Theme Builder v0.2.0 upgrades the visual studio into a complete, responsive design system. Instead of styling one block at a time, you can now manage site-wide brand colors, fonts, spacing, Light & Dark themes, reusable CSS classes, and Desktop/Tablet/Mobile layouts—all with live WCAG AA accessibility warnings and instant undo/redo.

Zero-FOUC & 1:1 Parity: When you click Publish, the studio writes the compiled tokens.css and builder.css files to /static/grex/ before promoting the live layout and clearing the cache—so visitors never see an unstyled flash.

2. Key v0.2.0 Features

Feature Where It Lives What It Does for Designers
Global Theme Token Editor Left Panel → Theme Tokens (createTheme) Edit brand colors, typography scale, spacing scale, radii, shadows, focus rings, and independent Light/Dark modes.
Live WCAG AA Contrast Warnings GREX-A11Y-001 in Studio & Inspector Automatically checks foreground/background color pairs in Light & Dark modes and warns whenever contrast drops below 4.5:1.
Bricks-Style Reusable Class Manager Inspector → Reusable Classes (createClassManager) Create, rename, duplicate, delete, and attach .grex-c-* classes so one edit updates matching elements across every template slot.
Responsive Breakpoint Switcher Top Toolbar (Desktop ≥ 1025px, Tablet ≤ 1024px, Mobile ≤ 767px) Resizes the live preview canvas and compiles deterministic media-query rules into /static/grex/builder.css.
Structured Visual Inspector Box Model, Layout, Typography, Border & Background Every style edit runs as a reversible command (setThemeToken, upsertClass, assignClass, setBreakpointStyle) with full undo/redo.
