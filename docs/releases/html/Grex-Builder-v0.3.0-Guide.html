Grex Theme Builder · Release v0.3.0

Grex Theme Builder v0.3.0

Conditional Theme Builder, Visual Query Loop Builder, Dynamic/Media/Menu Pickers & Live Preview Context Selector

Built on GRAB v1.1.0 · GrabLab CMS v1.0.0 · Grex JS v1.0.0 · Exclusive mode: "visual"

Plain-English Overview: Grex Theme Builder v0.3.0 elevates the visual studio into a complete conditional theme and query builder. Designers can assign distinct templates by content type, taxonomy term, or slug with automatic conflict detection, loop live GrabLab CMS entries with zero wrapper <div> elements, bind dynamic fields (keeping exact decimal prices), choose accessible media and navigation menus, and switch live preview contexts directly in the toolbar.

1. What Changed in v0.3.0

  • Conditional Theme Builder & Conflict Detection (GREX-TPL-CONFLICT): Manage multiple named templates across header, footer, home, single, archive, search, and 404 plus reusable global parts (card, hero, cta, sidebar). Rules resolve deterministically (entry_slug > taxonomy_term > content_type > all_posts / front_page > entire_site), support exclude overrides, and block publishing whenever colliding conditions share equal priority.
  • Visual Query Loop Builder (ForEach + GrabLab Query Feeds): Bind Grid, Stack, Section, or ForEach containers to GrabLab query_entries feeds filtered by content type, taxonomy term, custom fields, sorting, and pagination with clean <article> output and zero wrapper <div> bloat.
  • Dynamic Data Picker (Exact GrabDecimal / GrabInteger Precision): Bind text, headings, links, buttons, and images to entry.*, entry.custom_fields.*, term.*, and site.* via XSS-safe textContent and URL-protocol sanitization while keeping financial decimals such as "19.95" and "1,000.00" exact.
  • Media Library & Navigation Menu Pickers: Select assets from /api/media inside an accessible modal <dialog> enforcing WCAG AA alt text or explicit decorative toggle (GREX-A11Y-002), and bind Nav elements to /api/menus/{location} with semantic <nav><ul><li><a aria-current="page"> rendering.
  • Live Preview Context Selector (Preview As): Switch between Front Page, Specific Entry, Specific Term Archive, Search Results, and 404 Page in the studio toolbar to preview dynamic bindings and Query Loops live via GrexPreviewBridge while editing.
  • Deterministic Undo/Redo Command Stack: All new v0.3.0 actions (setTemplateConditions, upsertTemplate, configureQueryLoop, bindDynamicField, bindMediaAsset, bindNavigationMenu) execute as reversible commands shared with Groxy AI (grab mcp).
