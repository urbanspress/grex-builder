Grex Theme Builder v0.4.0

Immutable Publish Revisions, One-Click Rollback & Live GRAB-DESIGN-SYSTEM.md / grab mcp AI Guardrails

Built on GRAB v1.1.0 · GrabLab CMS v1.0.0 · Grex JS v1.0.0 · Exclusive mode: "visual"

Plain-English Overview: Grex Theme Builder v0.4.0 brings fearless publishing and safe AI co-design to the studio. Every Publish permanently records an immutable revision snapshot with deduplication, lets designers preview any past state side-by-side before restoring it with one click (CSS-first for zero flash of unstyled content), keeps a live GRAB-DESIGN-SYSTEM.md contract in sync with active tokens and classes, and enforces WCAG AA + structural guardrails on every incoming grab mcp / Groxy AI layout mutation.

1. What Changed in v0.4.0

  • Immutable Publish Snapshots (template_revisions): Migration migrations/002_revisions_schema.grab introduces the append-only template_revisions table storing complete point-in-time snapshots (templates, parts, conditional display rules, --grex-* theme tokens, and .grex-c-* classes), author metadata, summary, timestamp, and canonical SHA-256 hash with automatic duplicate suppression when nothing changed since the previous revision.
  • Semantic Revisions & Diff Drawer + Safe Live Preview: A new zero-wrapper-<div> Revisions drawer in the top toolbar displays the revision timeline, structured human-readable diffs across templates, conditional rules, theme tokens, and reusable classes, and a Preview This Revision button that renders any past revision live inside GrexPreviewBridge without affecting public visitors or draft state.
  • One-Click Zero-FOUC Rollback (POST /api/revisions/{id}/restore): Restoring a historical revision via the accessible confirmation <dialog> compiles and writes tokens.css and builder.css to /static/grex/ before updating studio_layouts and bumping the use cache epoch, regenerates GRAB-DESIGN-SYSTEM.md, and appends a new forward revision (e.g., Restored from Revision #N) so prior history is never lost.
  • Auto-Generated GRAB-DESIGN-SYSTEM.md Contract (GET /api/design-system.md): Every Publish and Restore automatically regenerates GRAB-DESIGN-SYSTEM.md containing active --grex-* tokens, reusable .grex-c-* class rules, approved 20-element semantic patterns, and conditional template rules so Groxy AI and grab mcp clients stay aligned with your design system.
  • grab mcp AI Layout Guardrails & 1-Click Undo (POST /api/mcp/layout, applyAiLayout): All incoming AI layout changes are strictly validated against validateElementNode() and WCAG AA auditAccessibility() (rejecting forbidden <div> wrappers, <script> / javascript: vectors, depth > 24, contrast < 4.5:1, and missing Image alt text with HTTP 422 / JSON-RPC -32602 before touching state). Valid AI edits commit to draft cleanly with actor: "groxy-ai", surface a notice badge in the studio, and support instant Ctrl+Z / toolbar Undo rollback.
